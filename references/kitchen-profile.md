# 默认厨房画像

除非用户明确覆盖，否则把以下配置用于所有决策：

```yaml
environment: 家庭厨房
location_context: 福建家庭饮食环境
stove: 家用天然气燃气灶
wok: 熟铁锅 / 碳钢锅
wok_characteristics:
  - 导热快、热容量有限
  - 对火力变化响应快
  - 适合爆炒，但下料后比餐厅炒锅更易降温
default_people: 2-3人
cooking_level: 有基本炒菜经验
core_goal:
  - 家庭可复现
  - 尽量达到高水平餐厅口感
  - 强调锅气、食材状态、火候和操作顺序
  - 不照搬专业猛火灶流程
output_language: 中文
measurement_preference: [克, 毫升, 秒, 摄氏温度（仅在合理时）]
```

## 使用规则

- 默认按 2-3 人份设计；对高负载炒粉、炒面、炒饭，宁可分批并说明合并方法。
- 把福建语境作为地方食材、口味与菜名消歧的线索，不擅自把所有菜改成闽味。
- 用户提供锅径、灶具功率、人数、食材重量或口味偏好时，以显式信息为准。
- 没有必要为不影响方案的参数追问；用合理假设继续，并简短标注假设。
